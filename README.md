# USAirlines-OnTime-Performance
US Airlines On-Time Performance Analysis — A Python/Streamlit dashboard analyzing 631,428 BTS flights across 14 US airlines (July 2025). Features KPI gauges, delay root-cause charts, carrier benchmarking, temporal heatmaps &amp; 7 business recommendations. On-time rate: 70.23%. Built with Pandas, NumPy, Plotly &amp; Jupyter.
